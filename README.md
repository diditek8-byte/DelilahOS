Delilah OS

A web-based operating system inspired by modern desktop environment.
This project is currently a work-in progress for the Hack Club Stardance event!

Features
- Desktop Top Bar
- Draggable Windows
- Time & Date
- About Me Window
- Really cool self designed background
- Notes App
- Random Quotes Generator App
- Desktop Bottom Bar
- Green beam that follows the mouse
- Weather App
- Calculator
- Random Quotes Generator App
- Loading Page
- Calendar Widget
